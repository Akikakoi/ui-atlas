令牌 / 基础 / 动效

把节奏，
写成令牌。

160ms 用于即时反馈，280ms 用于视图切换；超过 400ms 的缓动在密集界面里会显得拖。曲线统一走 --ease-out，减速比加速更像「落位」。

更新于 3 天前·维护者 林一·已随 v2.4.0 发布
tokens.css CSS 
/* 动效令牌 —— 复制后直接可用 */
:root{
  --motion-fast: 160ms;
  --motion-base: 280ms;
  --ease-out: cubic-bezier(.2,.8,.2,1);
  --accent: #8ef0c8;
}
4 个令牌 · 已包含在 @motif/tokensCSS · UTF-8

什么时候用哪个

先选时长，再统一曲线；不要为单个组件单独发明缓动。

令牌值用在哪
--motion-fast160ms按压、hover、开关切换
--motion-base280ms弹层、抽屉、页面转场
--ease-outcubic-bezier(.2,.8,.2,1)所有进入与位移；退出可换 ease-in
减动效不是删过渡。在 prefers-reduced-motion: reduce 下把时长压到 1ms，状态仍然要变，只是不移动；颜色与透明度可以保留。
