FORM INSTITUTE / SHAPE STUDY

一条路径，
三种形态。

我们在研究「连续」这件事：圆如何变成方，方又如何收成三角。没有两次跳变，只有一条被逐点插值的路径——以及跟着进度一起变化的颜色与角度。

METHOD / 方法

让形变可被计算。

01 / SAME LENGTH

等长路径

三种形态都用「1 个 M + 4 个 C + Z」描述，控制点数量完全一致，才能逐坐标相加。

02 / INTERPOLATE

逐点插值

前 50% 把圆拉成圆角方，后 50% 再把方收成三角；每段都先做 smoothstep，再线性混合。

03 / SYNCHRONIZE

同步通道

颜色从蓝到紫再到橙，旋转从 −30° 到 +30°，和路径共用同一个进度值，不各跑各的。

为什么不用 CSS 过渡。

路径不是数字。 d 属性里是一长串坐标，浏览器不会在两个 path 之间自动补间。我们把它拆成 26 个数字，自己按进度做 lerp，再拼回路径字符串。

滚动是唯一的时钟。 区域高度设为 260vh，视口用 sticky 固定；取区域滚过的比例作为 0→1，来回滚动都能停在同一进度对应的形态上。

阶段标注怎么来。

进度小于 0.25 标为「圆」，0.25—0.75 标为「圆角方」，大于 0.75 标为「三角」，对应右侧列表同步高亮，给出形变的语义而不仅是视觉。

若开启「减少动态效果」，脚本直接渲染第 1 帧——也就是最终三角——并停止监听滚动；形态依旧可见，只是不再随页面推进。
