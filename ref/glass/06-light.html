换成浅色，动了什么

surface5.5% / 9% / 14% → 55% / 72% / 88%
accent#7aa2ff → #2a5bd7（浅底上必须更深）
shadow深色靠黑影 → 浅色只能靠很淡的蓝灰影
光斑透明度反而要更高，否则面板变成一片奶白

表单在同主题下

浅色玻璃比深色难。 深色靠「白上叠白」自然分层；浅色必须在白上叠白的同时加蓝灰色偏移， 否则所有面板糊成一片奶白。这也是为什么 token 里要有 --surface-1/2/3 三档而不是一个透明度—— 切主题时真正变化的是这三档的关系，不是某个色值。
